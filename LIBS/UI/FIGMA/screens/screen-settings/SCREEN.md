# screen-settings
**Intent:** one settings surface. House system · Model (catalogue rows with size, real download progress, storage used, remove; the designated trial model is flagged, others locked behind the unlock — D11) · Voice (Kokoro voice picker, preview, mute; identical on web, where Kokoro runs in-browser via onnxruntime-web per D7a) · **License · trial or unlimited** (status `[trial · readings left · runtime]` / `[unlimited]`, unlocks date, Restore purchases, Enter a code — D11) · Data (export JSON incl. lore, import, delete everything; **Lore · what she remembers**: `[turns · nodes · runtime]` summary and lore-deletion — D12) · About link.
**Variants:** model absent · download in progress (real percentage) · web (1280 wide; same rows, Kokoro voice included per D7a) · trial vs licensed License section states.
**Content classes:** authored-static labels, computed-fact values (runtime markers for status, turns, nodes).
